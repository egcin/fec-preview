# Emek Hukuk — Site Önizleme

Bu depo, Emek Hukuk Danışmanlık ve Arabuluculuk Merkezi web sitesinin **yayın öncesi önizleme** kopyasıdır. İçerik avukat incelemesi aşamasındadır ve henüz `emekarabuluculuk.com` üzerinde yayında değildir.

## Yayın

Önizleme adresi: https://egcin.github.io/fec-preview/

`robots.txt` üzerinden arama motoru indekslemesi kapatılmıştır; bu sayfa Google sonuçlarında çıkmaz, yalnızca bağlantıyı bilen kişiler ulaşabilir.

## Güncellemeler

Bu önizleme, ana depodaki (`egcin/fec`) `main` dalına her commit sonrasında otomatik olarak güncellenir.
